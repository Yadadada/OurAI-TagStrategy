- **运行方式**：`npx tsx scripts/run-eval.ts --field q22 --no-llm`
- **数据集**：种子样本 v1（Q22=15 条）

### 核心数字

### 按 category 分桶

| category | Q22 准确率 |

### 关键观察

1. 关键词降级在 normal 类只有 42.9%——预设子标签覆盖范围有限，"展览"、"羽毛球"、"逛逛"、"好吃的"等真实表达不在 `tagTree.ts` 的 `presetSubs` 列表里就抓不到
2. longtail 类 0%——网络用语（citywalk、探店）完全无法识别
3. empty 类 100%——`EMPTY_TEXT_PATTERNS` 的硬编码空判规则可靠

### 用途

作为"无 LLM"的下界基线，证明纯关键词法的天花板很低，为 LLM 引入提供动机。

## Baseline #1 — LLM 零样本（GPT-4.1，无 few-shot，无 CoT）

- **时间**：2026-05-31
- **代码 commit**：`797256e`
- **模型**：gpt-4.1（通过本地 OpenAI 兼容 proxy）
- **运行方式**：`npx tsx scripts/run-eval.ts`
- **数据集**：种子样本 v1（Q22=15、Q23=15、Q24=16，共 46 条）
- **报告文件**：`eval/results/report-2026-05-31T10-24-00.md`
- **运行次数**：1（待补 3 次取平均）

### 核心数字

| 指标 | Q22 | Q23 | Q24 | 整体 |
|---|---|---|---|---|
| 主标签准确率 | **93.3%** | **100.0%** | **93.8%** | **95.7%** |
| 子标签宽松命中率 | 75.0% | 75.0% | 69.2% | ~73% |
| 空判召回率 | 100.0% | 100.0% | 100.0% | 100.0% |
| 互动维度准确率 | 80.0% | — | — | — |
| 平均耗时 | 1288ms | 1310ms | 1228ms | 1274ms |

### 按 category 分桶（主标签准确率）

|---|---|---|---|
| normal | 100.0% | 100.0% | 100.0% |
| longtail | **50.0%** | 100.0% | **50.0%** |
| boundary | 100.0% | 100.0% | 100.0% |
| empty | 100.0% | 100.0% | 100.0% |
| perturbation | 100.0% | 100.0% | 100.0% |

### 错误样本（2 条，全部出在 longtail）

| 样本 | 文本 | 期望 | 实际 | 性质 |
|---|---|---|---|---|
| q22-010 | 一起出门探店 | `food_social` | `stroll` | 网络用语歧义：探店在小红书语境兼具"逛"和"吃" |
| q24-011 | 不喜欢爹味重的男的 | `values` | `personality` | 网络用语跨主标签：爹味既是性格表现也是价值观体现 |

### 关键观察

1. 相比 fallback 基线 53.3%，LLM 整体准确率 95.7%，**提升 42.4 个百分点**——证明 LLM 语义理解的价值
2. normal/boundary/empty/perturbation 四个类别接近天花板（≥93%）
3. **longtail 是唯一短板**——这是 prompt 调优（方向 3）需要解决的核心问题
4. 发现一个工程细节：`EMPTY_TEXT_PATTERNS` 不包含"还没想好"、"想不到啥"等近义表达，会触发不必要的 LLM 调用（虽然最终结果靠 fallback 兜底）

### 用途

作为零样本 LLM 的"上界基线"，后续所有 prompt 调优实验（few-shot、CoT、模型替换）都和这份对比。
