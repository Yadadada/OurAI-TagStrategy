### 2. 种子样本到底谁来写

**日期**：2026-05-22
**对应决策**：[ADR-004 评测数据集构造](../decisions/ADR-004-eval-dataset-construction.md)

**用户**：怎么写种子样本？我可以自己来写吗？

**Claude** 的建议：**强烈推荐用户自己写**，理由如下：

1. **场景理解更准**——校园交友的真实表达方式（同学怎么说话、什么样的回答算"自然"），用户的直觉比 LLM 更准
2. **种子是后续所有数据的锚点**——种子写得偏，后面 LLM 扩充的 250 条全跟着偏。用户自己写，质量更可控
3. **写的过程能暴露标签设计的问题**——比如"打球完吃饭"这种回答没法干净归到一个主标签，这就是 PPT 里很好的"方法局限"讨论点
4. **PPT 汇报时更有底气**——负责人问"你的标注标准是什么"，自己写过就答得出来

**结论**：种子样本由用户手工写（46 条），LLM 只用来做后续扩充和抽检兜底。这个分工直接固化为 ADR-004 的"三段式数据集构造法"。

### 3. 一起打球算不算强互动

**日期**：2026-05-27
**对应决策**：[ADR-006 互动维度规则收紧](../decisions/ADR-006-interaction-mode-rule-tightening.md)

**用户**：我觉得一起打球之类的运动属于强互动。

**问题定位**：

试跑 LLM 扩充时发现：
- 种子 `q22-005` "一起约着打场羽毛球" → `expected_interaction: "strong"` ✅
- 扩充 `q22-exp-005` "第一次见面可以一起打羽毛球" → `expected_interaction: null` ❌

LLM 在生成扩充数据时没坚持这条规则。**根因**：当前 prompt 对 strong 的定义只覆盖对话类关键词（聊聊天/分享/深聊…），身体协同型互动没被覆盖。

**Claude 反问澄清规则边界**：

- Q1：什么样的运动算 strong？
  - (a) 所有"一起"做的运动都算
  - (b) 只有需要双方协作/对抗的运动算（羽毛球、篮球、桌游对战），各自做的（一起跑步、一起健身）不算
  - (c) 只要文本里有"一起/约着/陪我"等共同参与的词且涉及运动就算
- Q2：单纯一起吃饭、没提聊天，算 strong 还是 null？

**用户拍板**：

> 交互式的两人协作型运动算强互动，多人的桌游或者两个人一起跑步这种不算。

**结论**（写入 ADR-006）：

| 运动类型 | 互动维度 | 例子 |
|---|---|---|
| 双人对打 | **strong** | 羽毛球、网球、乒乓球、对打、双打 |
| 多人对抗 | **null** | 足球、篮球（除非明确说一对一） |
| 并排进行 | **null** | 一起跑步、一起爬山、一起健身 |
| 平行体验 | **null** | 一起看电影、一起逛展、桌游 |

**落地动作**：
1. 改 `tagTree.ts` 的 `Q22_INTERACTION_MODES.strong` 描述 + 关键词
2. 跑 Baseline #1.5（46 条种子，5 分钟）做廉价回归测试，确认规则改动不引起旧基线回退
3. 修扩数据 prompt，让 LLM 生成时遵守这条规则

## 这三段对话沉淀的方法论

1. **战略层先定**：方向优先级写进 CLAUDE.md，每轮对话自动加载，避免漂移
2. **关键标注用户自写**：种子=金标准，AI 只做扩充+抽检
3. **规则改动先做廉价回归**：标签树/规则改动 → 跑种子集 5 分钟拿到回归结论 → 再扩量
