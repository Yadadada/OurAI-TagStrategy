# ADR-006: 互动维度规则收紧 — 双人对打 vs 并排活动

**状态**：已实施
**日期**：2026-05-31
**决策者**：项目组

## 背景

ADR-003 把"聊天/交流"从场景主标签中拆出来作为横切的 `interaction_mode` 维度（strong / weak / null）。原始定义里 strong 的关键词只有"聊聊天、深聊、谈心"等纯语言互动信号。

数据集扩充阶段，标注员发现一个边界没定义清楚：**"打羽毛球" / "踢足球" / "一起跑步"这类运动，应该归 strong（强互动）还是 null（无互动信号）**？

这三种运动看似都是"两人一起做"，但本质不同：
- **羽毛球/网球/乒乓球**：必须双方持续配合 / 对打，节奏被对方决定，互动密度高
- **足球/篮球**：多人活动，单个用户和约会对象未必直接对位
- **一起跑步**：两人并排进行，但各跑各的节奏，没有持续配合

如果不收紧规则，标注员之间会产生分歧，扩充样本质量下降。

## 决策

**双人对打类运动 = strong；多人/并排运动 = null**。

### 收紧后的规则

| 运动类型 | 互动维度 | 例子 |
|---|---|---|
| 双人对打 | **strong** | 羽毛球、网球、乒乓球、对打、双打 |
| 多人对抗 | **null** | 足球、篮球、排球（除非文本明确说"一对一打" |
| 并排进行 | **null** | 一起跑步、一起爬山、一起健身、一起游泳 |
| 平行体验 | **null** | 一起看电影、一起逛展、桌游（多数桌游不是"对打"） |

### 规则落地位置

修改 `tagTree.ts` 的 `Q22_INTERACTION_MODES.strong.description` + `keywords`，从纯语言关键词扩充为"语言 + 双人对打"两类。抽取端 prompt 自动同步（prompt 里直接 import 这些常量）。

```typescript
strong: {
  label: '强互动',
  description: '聊天/深聊/分享/讨论；或两人协作/对抗型运动（羽毛球、网球、乒乓球等需要双方持续配合的对打类）',
  keywords: [
    '聊聊天', '分享近况', '深入交流', '谈心', '聊天', '聊聊', '深聊', '畅谈',
    '打羽毛球', '打网球', '打乒乓球', '对打', '双打',
  ],
},
```

### 回归测试：Baseline #1.5

规则改动后，必须验证不引起 LLM 旧基线回退。用种子集（46 条，5 分钟）跑一次廉价回归测试 = **Baseline #1.5**。

结果：所有指标与 Baseline #1 完全持平（整体 95.7%，错误样本仍为同两条），证明规则收紧是安全的。

## 为什么不选其他方案

- **保持原规则不动**：标注员分歧无法解决，扩充样本质量下降
- **把所有运动都归 strong**：会把"一起跑步"这种各跑各的也算强互动，违背用户意图
- **新增第三档 "medium"**：标签体系复杂度上升，下游消费方不知道怎么用
